# Age Calculator

This is a simple web-based Age Calculator application that calculates your age based on your date of birth. The application uses HTML, CSS, and JavaScript to provide an interactive user experience.

## Features
- Displays the current date.
- Accepts a date of birth in the format MM/DD/YYYY.
- Calculates and displays the user's age in years.
- User-friendly interface with responsive design.

## Project Structure
```
├── index.html   # Main HTML file
├── style.css    # Styling for the application
├── script.js    # JavaScript for age calculation logic
```

### index.html
- Contains the structure of the web application.
- Includes a container for user input and the display of the calculated age.

### style.css
- Styles the layout and design of the application.
- Enhances the user interface with colors, shadows, and responsive elements.

### script.js
- Handles the age calculation logic.
- Displays the current date and calculates age based on user input.

## How to Use
1. Clone or download the repository.
2. Open `index.html` in any modern web browser.
3. Enter your date of birth in the specified format (MM/DD/YYYY).
4. Click on the **Age** button to calculate your age.
